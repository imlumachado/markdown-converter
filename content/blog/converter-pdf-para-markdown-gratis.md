# Converter PDF para Markdown grátis e sem cadastro

PDF é ótimo para compartilhar, mas ruim para editar. Se você precisa do
conteúdo em texto editável, converter PDF para Markdown é a solução —
e você não precisa instalar nada.

## Vantagens do Markdown sobre o PDF

- Texto editável e leve.
- Fácil de versionar com Git.
- Compatível com blogs, wikis e sites estáticos.
- Sem travamentos de formatação.

## PDFs digitalizados (OCR automático)

Documentos que são apenas imagens (digitalizações) também funcionam.
O conversor usa OCR (reconhecimento óptico de caracteres) para extrair
o texto automaticamente, com suporte ao **português**.

Isso significa que você pode converter:

- Contratos e documentos assinados.
- Livros e apostilas digitalizados.
- Recibos e notas fiscais em imagem.

## Passo a passo

1. Abra o site e arraste o PDF.
2. Aguarde a conversão (páginas digitalizadas demoram mais).
3. Revise o preview.
4. Baixe o arquivo `.md`.

## Perguntas comuns

**O tamanho máximo é quanto?**
O limite é de 25 MB por arquivo.

**Preciso criar conta?**
Não. É gratuito e não exige cadastro.

**Meus arquivos ficam salvos?**
Não. Os arquivos são excluídos logo após a conversão.
