# Como converter Excel para tabelas Markdown

Planilhas do Excel (XLSX) são ótimas para organizar dados, mas difíceis
de exibir em um README ou em documentação. A solução é converter as
planilhas em **tabelas Markdown**.

## Quando usar tabelas Markdown

- Documentação técnica.
- README de projetos no GitHub.
- Publicações em sites estáticos.
- Conteúdo de wikis.

## Como funciona a conversão

Cada planilha do arquivo é convertida em uma tabela Markdown, com
cabeçalho, linhas e colunas preservados.

| Recurso do Excel | Conversão |
|---|---|
| Cabeçalhos de coluna | Linha de cabeçalho da tabela |
| Células com texto | Texto simples |
| Números | Mantidos como estão |
| Fórmulas | Valor calculado |

## Passo a passo

1. Acesse o conversor.
2. Arraste o arquivo `.xlsx`.
3. Veja o preview das tabelas.
4. Baixe o `.md` e use onde quiser.

## Dicas

- Nomeie suas colunas de forma clara na primeira linha.
- Evite mesclagem excessiva de células.
- Remova linhas em branco antes de converter.

Converta quantos arquivos quiser — é gratuito e sem limite de usos.
