# Converter PowerPoint para Markdown em segundos

Apresentações em PowerPoint (PPTX) são ricas em conteúdo, mas nem sempre
é fácil extrair o texto para usar em outra ferramenta. Converter para
Markdown organiza cada slide em títulos e listas legíveis.

## O que você ganha

- Todo o texto de cada slide em um arquivo `.md`.
- Estrutura limpa com títulos por slide.
- Conteúdo pronto para documentação ou blog.
- Arquivo leve e editável.

## O que é convertido

| Elemento do slide | Resultado no Markdown |
|---|---|
| Título do slide | Cabeçalho |
| Textos e bullets | Listas |
| Conteúdo em destaque | Parágrafos |

## Como converter

1. Abra o site.
2. Arraste o arquivo `.pptx`.
3. Aguarde o preview.
4. Baixe o Markdown.

## Para quem é útil

- Desenvolvedores documentando apresentações técnicas.
- Estudantes organizando conteúdo de aulas.
- Criadores de conteúdo adaptando slides para artigos.

Rápido, gratuito e sem instalação. Seus slides são processados
