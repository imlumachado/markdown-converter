# Guia de sintaxe Markdown para iniciantes

Markdown é uma linguagem de marcação leve usada para formatar texto de
forma simples e legível. Este guia cobre a sintaxe essencial para você
começar.

## Títulos

Use `#` para títulos. Quantos mais `#`, menor o nível.

```
# Título 1
## Título 2
### Título 3
```

## Ênfase (negrito e itálico)

```
**negrito**
*itálico*
***negrito e itálico***
```

## Listas

**Não ordenada:**

```
- item 1
- item 2
```

**Ordenada:**

```
1. primeiro
2. segundo
```

## Links

```
[texto do link](https://exemplo.com)
```

## Imagens

```
![descrição da imagem](caminho/da/imagem.png)
```

## Tabelas

```
| Coluna 1 | Coluna 2 |
|---|---|
| A | B |
| C | D |
```

## Blocos de código

Inline com crases:

```
`código inline`
```

Em bloco com três crases:

````
```
linha de código
```
````

## Citações

```
> isto é uma citação
```

## Linha horizontal

```
---
```

## Dicas rápidas

- Deixe uma linha em branco entre blocos para melhor renderização.
- Use a sintaxe consistente: escolha `-` ou `*` para listas e mantenha.
- A maioria dos editores mostra o resultado em tempo real.

## Por que usar Markdown?

- É **texto puro** — abre em qualquer editor.
- **Funciona com Git** e controle de versão.
- É o formato padrão de **READMEs** e documentação.
- Converte facilmente para HTML, PDF e outros formatos.

Agora que você conhece a base, experimente converter um documento Word
ou PDF para Markdown e veja a estrutura gerada na prática.
