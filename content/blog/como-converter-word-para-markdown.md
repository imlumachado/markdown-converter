# Como converter Word para Markdown

O Markdown é um formato de texto simples que se tornou padrão para
documentação, blogs e repositórios. Converter um documento Word (DOCX)
para Markdown é útil quando você quer publicar conteúdo na web sem a
formatação pesada de um editor de texto.

## Por que converter DOCX para Markdown?

- **Portabilidade:** arquivos `.md` abrem em qualquer editor.
- **Controle de versão:** o Markdown é texto puro, ideal para Git.
- **Publicação:** blogs e sites estáticos aceitam Markdown nativamente.
- **Leveza:** um arquivo .md é muito menor que um .docx.

## O que é preservado na conversão

| Elemento | Suporte |
|---|---|
| Títulos (H1–H6) | Sim |
| Listas ordenadas e não ordenadas | Sim |
| Tabelas | Sim |
| Links | Sim |
| Imagens | Sim |

## Como usar o conversor

1. Acesse a ferramenta na página inicial.
2. Arraste o arquivo `.docx` ou clique para escolher.
3. Aguarde o preview do Markdown gerado.
4. Baixe o arquivo `.md`.

## Dicas para melhor resultado

- Use os estilos nativos do Word (Título 1, Título 2, etc.).
- Evite texto em caixas de texto flutuantes.
- Prefira tabelas simples para conversão mais limpa.

O conversor exclui automaticamente os arquivos após a conversão, então
seus documentos não ficam armazenados.
